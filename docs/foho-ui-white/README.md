# FoHo — утверждённая белая версия

Готовая вёрстка для переноса в существующий проект. Светлый фон, чёрная типографика, синий акцент `#2457F5`, локальный шрифт Golos Text и оригинальный логотип FoHo. Все ресурсы находятся внутри архива, CDN и npm-зависимостей нет.

## Как открыть

Распакуйте архив. Откройте `index.html` через статический HTTP-сервер вашего проекта. Для отдельного просмотра можно выполнить из папки пакета:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080/`. Сборка не требуется. Прямое открытие через `file://` может ограничивать загрузку шрифта и работу History API.

## Экраны

| Файл | Экран |
| --- | --- |
| `index.html`, `upload.html` | Загрузка: категории, подсказка со стрелкой, контур загрузки, выбранный файл |
| `audit.html` | Аудит: реквизиты, таблица, фильтры, пагинация, карточка товара |
| `template.html` | Выбор вертикальных наклеек или горизонтальных бирок |
| `export.html` | Подтверждение параметров перед созданием PDF |
| `generating.html` | Полноэкранная анимация создания с меняющимися подписями; затем переход к скачиванию |
| `ready.html` | Готовый файл и скачивание |
| `importer.html` | Форма реквизитов импортёра |

Это отдельные точки входа в общий интерфейс, а не независимые приложения. Для переноса в существующий роутер используйте общую оболочку из `index.html` и соответствующие функции отрисовки из `js/ui.js`.

CSS подключается в порядке: `components.css` → `white.css` → `layout.css`. Белая тема зафиксирована атрибутом `data-theme="mono"` у `<html>`. Переключателя тем нет, параметр `theme` не меняет оформление.

## Граница готовности

Это комплект интерфейса и анимаций. Чтение Excel, бизнес-валидация, сохранение реквизитов и генерация PDF не реализуются этим пакетом. В просмотре использованы фиксированные строки из исходных экранов; выбор любого файла не означает его обработку. Анимация создания завершается по таймеру 7,2 с, а ссылка PDF скачивает фиксированный образец.

Ссылка «Скачать шаблон для заполнения ↗» оформлена, но исходный шаблон Excel не предоставлен. Для включения скачивания укажите его URL в `js/config.js`. Новый формат Excel не придумывался.

Автоматически проверены синтаксис JavaScript, точки входа, ссылки на локальные ресурсы, фиксация белой темы и базовое переключение UI-состояний. Визуальная проверка в браузере при подготовке архива была недоступна.
