# Анимации утверждённого интерфейса

| Элемент | Реализация | Параметры / условия |
| --- | --- | --- |
| Подчёркивание ссылок и «Назад» | `layout.css`, `:after`, `scaleX` | 0,36 с, раскрытие слева направо; hover и клавиатурный focus |
| Стрелка к категориям | `category-guide.js` + `layout.css` | Цикл 3 с; прорисовка и исчезновение по контуру, без перемещения |
| Привязка стрелки | SVG path | Начало справа от текста на высоте его середины; конец под серединой группы категорий |
| Бегущий отрезок границы загрузки | SVG `rect`, `stroke-dashoffset` | Цикл 5 с; тонкая линия поверх постоянной границы, только в ожидании файла |
| Иконка загрузки | SVG + CSS | Без наклона, небольшой вертикальный hover |
| Карточки шаблонов | CSS transform | Лёгкий подъём карточки и движение абстрактной формы |
| Объёмные документы | `motion.js`, Canvas 2D с проекцией | Семь листов, толщина, тени, частицы, сканирующая линия |
| Создание PDF | Canvas `data-mode="generating"` | Крупная сцена на весь экран и подпись; сборка стопки около 4,9 с |
| Смена подписи | `generationCaption`, CSS `caption-word` | Появление слов по очереди; задержка 65 мс между словами |
| Подписи просмотра | `generate()` | 0 с — страницы; 2,3 с — сборка PDF; 4,8 с — завершение; готовность в 7,2 с |
| Переходы экранов | Web Animations API | Слои, закрытие сцены и раскрытие новой; основная длительность 1,12 с |
| Готовность → скачивание | `navigate('ready')` | Тот же стандартный переход, подпись «Скачать PDF» |
| Уведомление | CSS + UI-таймер | Появление снизу, автоматическое скрытие |

## Доступность и производительность

- `prefers-reduced-motion: reduce` отключает движения; стрелка остаётся видимой, переход выполняет смену состояния без анимации.
- Canvas останавливается в скрытой вкладке. При возвращении цикл возобновляется.
- Кастомного курсора и магнитных кнопок нет. Нативный курсор сохранён.
- У Canvas есть слабая реакция перспективы на указатель; на touch она не используется.
- Направляющая стрелка пересчитывается при изменении размеров и после загрузки шрифта.

Для сохранения анимаций оставляйте классы, `data-mode`, ID `stage` и структуру SVG. При изменении состояния интерфейса после замены DOM вызывайте `FohoMotion.sync()`.
